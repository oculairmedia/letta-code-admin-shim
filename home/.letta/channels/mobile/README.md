# Mobile channel plugin for letta-code

User-defined channel plugin loaded from `~/.letta/channels/mobile/`. Unlike
Matrix (which long-polls an external homeserver), this channel is **inbound**:
the admin-shim hosts a WebSocket upgrade route at `/shim/v1/mobile`, and the
plugin owns the per-connection protocol — auth handshake, frame reshaping,
otid binding, run correlation, cancel routing.

The plugin is the transport that backs `letta-mobile`. See
`/opt/stacks/letta-code-parallel/docs/MOBILE_CHANNEL_DESIGN.md` for the wire
contract and `/opt/stacks/letta-code-parallel/admin-shim/docs/DIVERGENCE.md`
for shim-side notes.

## Type definitions

This plugin stays as `.mjs` by design — the admin-shim loads it at runtime
via dynamic `import()`, no build step. To get editor hints, opt into the
TypeScript declaration the shim ships:

```js
/// <reference path="../../../../admin-shim/dist/lib/types/channel-plugin.d.ts" />
```

The `.d.ts` is generated by `npm run build` in `admin-shim/`. See
`admin-shim/docs/CHANNEL_PLUGINS.md` for the full opt-in pattern, including
the `MobileChannelExtras` sub-interface that types `acceptConnection`.

## File layout

```
~/.letta/channels/mobile/
├── channel.json
├── plugin.mjs                # adapter + lifecycle (createAdapter / start / stop)
├── accounts.json             # MOBILE_CHANNEL_TOKEN auth config
├── lib/
│   ├── protocol.mjs          # frame shapes + reshaping helpers
│   ├── ws-handler.mjs        # per-connection state machine
│   └── state.mjs             # in-memory client registry
└── test/ws-smoke.mjs         # standalone end-to-end exerciser
```

## Smoke test

With the shim running and `MOBILE_CHANNEL_TOKEN` exported:

```bash
node ~/.letta/channels/mobile/test/ws-smoke.mjs \
  --token "$MOBILE_CHANNEL_TOKEN" \
  --agent agent-XXXX-...
```
